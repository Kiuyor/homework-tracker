# 视觉演进继续留在「白板风」骨相内，不引入卡片与品牌识别色

2026-09-19 一轮以"整体视觉方向重做"为出发点的对齐，在逐条比较四种走向之后决定：**骨相不动**，本轮全部改动发生在"白板风"之内——把失控的取值收进体系，而不是换一套长相。

被明确否决的三个备选：

- **引入卡片 / 底色 / 纵深**：这要推翻 `style.css` 顶部那句"白板上只有文字，无卡片、无投影、无装饰"。视觉变化最大，代价是工单 027 刚验收的"内容完整 + 后排可视"整轮重测。
- **翻转为暗色默认**：现状是白底为默认、暗色为手动选项。
- **品牌识别色**：给产品一个自己的颜色，出现在 brand 与展示态角标上——它是纯装饰，与"无装饰"正面冲突。

**取舍理由**：本产品唯一职责是让教室后排看清今天的作业，克制本身就是功能，不是没做完。

**后果**：今后任何"让墙更好看"的诉求只能在 token 层与层级（字重 / 字号 / 留白）上解决，**不得以加装饰的方式解决**。要推翻本条需要新 ADR 显式作废，不接受"顺手加个阴影"这种既成事实。

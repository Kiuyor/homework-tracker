# 主色只归动作，内容区永不用主色

`--accent` 定义在 `style.css:31` 之后**使用 0 次**，全站没有一个承担"这里可以按"含义的颜色。本轮定色为**深靶蓝**（色相 ≈235，白底对比度 ≥4.5:1，暗色模式另设一档），并同时给它一条职责边界：**只出现在可被按的东西上**——按钮、选中态、焦点环。科目名、正文、截止时间等内容区一律不用。

**取舍**：备选有"语境取色"（按钮取当前格的科目色，视觉最统一于科目）——被否决，因为顶栏、模态、toast 这些没有科目归属的语境仍然要一个兜底色，等于绕回本方案；以及"继续用墨色、不引入色相"（改动最小）——被否决，因为那样 `--accent` 这个 token 依旧等于没有内容，本轮就没有主色可言。

**为什么不躲科目色池**：12 色池几乎占满色轮（红 5°、橙 19°、琥珀 32°、橄榄 84°、绿 119°、青绿 172°、青 192°、蓝 215°、紫罗兰 262°、紫 297°、品红 325°、粉 330°），按"拉开色相距离"去挑主色基本无处可去。本决策不依赖色相距离成立——动作只出现在控件、科目色只出现在内容区，两者在空间上本就不相邻，撞不撞由职责边界化解。

**后果（两条）**：

1. 展示态顶栏与行内按钮均不可见，能承载主色的控件只剩「退出展示」「A−」「A+」三个——**学生几乎看不到主色**，它的受众是操作时的科代表。今后任何"让主色更显眼"的诉求都要先回答这一条。
2. 焦点环统一为主色 2px。`style.css:532` 那条 `outline: none`（模态内 input/textarea/select 抹掉焦点环）与 `:295` 那条正常的 `.subject-filter:focus-visible` 不一致，属违规，本轮清除。

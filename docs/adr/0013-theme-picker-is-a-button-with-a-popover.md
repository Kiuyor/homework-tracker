# 主题入口是一颗按钮，选项在它自己的弹层里

2026-09-25 的改口。ADR-0012 把主题切换入口定为「编辑态工具行里一个四选一分段选择器（复用 `.seg`）」，工单 002 照此落地（两档时是两颗常驻钮）。落地后要求改成：**工具行只常驻一颗入口钮，选项装在这颗钮自己的弹层里，点开才在**。

**本 ADR 作废 ADR-0012「主题切换入口」段的第一句**（四选一分段选择器常驻）。那一段里其余三条**继续有效且本 ADR 不碰**：投影时不给切换入口、展示态不出现主题控件（`verify-47a.js` 故事 9 判据不变）、收起顶栏后主题不可改（ADR-0010 后果 1「没有部分控件仍可用的中间态」原样成立）。spec `2026-09-25-…` 故事 13 的形状、故事 16 的判据形式随本条改；故事 14/15/17/18/20/21/22/23/24 一字不动。

**改口的理由是宽度账，不是观感。** ADR-0012 那笔账只算了 1366 一头：现状整组约 540px + 四选一约 300px ≈ 840px < 可用 1270px，看着宽裕。但同一支名单在 390px 那头是**每颗常驻段钮都要占掉的一整格**——工具行的 `flex-wrap` 会为一颗 300px 的控件多出至少一行，而那一行只有它。常驻控件的代价按「名单长度 × 每一个窄屏」付，弹层把它换成「一颗钮 × 任意名单长度」。实测（真页面、同源 iframe 逐宽度，非源码推算）：

| 名单长度 | 入口钮 | 弹层 | 单项命中区 | 390px 下横向滚动 |
| --- | --- | --- | --- | --- |
| 二档（002 现状） | 98×44 | 98×98 | 96×48 | 无 |
| 四档（模拟填齐） | 116×44 | 116×194 | 114×48 | 无（右边缘 245 < 390） |

> **〔007 重量这行表，读数在 `.scratch/四主题体系/geom-toolrow.json`〕** 第二行的三个数**今天复现不出来**：007 把名单临时补到 4 项实测入口 97.6×44、弹层 97.6×194、单项 95.6×48，390px 那头 left 274.2 → 右边缘 371.8（不是 245），仍不出血口、仍不撑横向滚动。第一行（98×44）复现得出（97.6×44，同一支名单）。差异原因**没查**——只记"取不出那串数"，不写归因。**这张表的本 ADR 论证部分是"宽度随名单长度变、弹层把代价从『钮数 × 窄屏数』换成『一颗钮』"，那条在两种读数下都成立**，所以决定本身不受影响。

入口文案由 `ui.js` 写成「主题 · 当前档」，所以**不打开也读得出现在选的是哪套**——这是常驻段钮免费给的东西，换成弹层必须换个方式给回去，否则窄屏省下的那一行要用「看不清当前档」来换，不划算。

**弹层带来的三条新约束，是本 ADR 的真正内容：**

1. **开着一个浮层就必须有第二条出路。** 选完自动收、点弹层外面收、Esc 收、收起顶栏收、切展示态收——五条都收在同一个函数 `window.setThemePop(false)` 上。
2. **开合状态只许一处作者。** 切档会触发选项整批重绘（`renderThemeSeg`），重绘若顺手改开合，「点选项 → 收弹层」那条就变成两处作者互相遮掩。**机制探针两个方向都量**：收起时重绘仍收起、打开时重绘仍打开——只量前者会漏掉后半，而漏掉后半正是重复作者藏身的地方。
3. **弹层是 ADR-0012 决定 5 那四类浮层里的「弹层」。** 玻璃档可以给它材质（`backdrop-filter`），但它仍然拿不到科目色与内容色——ADR-0009 那条边界不因新增浮层而移动。

**取舍**：备选「用原生 `<select>`」被否决——入口会与工具行其余三件（自绘钮）不同形，且系统选择器的展开形态在各触屏浏览器里不可控，本站没有为它让过尺寸（**未实测，这是一条凭形态而非凭读数的否决，谁要翻案先补读数**）。备选「弹层换成模态弹窗」被否决——模态盖住墙面，而选主题这个动作恰恰要看墙。备选「入口挪到顶栏第一行」被否决——第一行是品牌与动作，显示设置归工具行，这条是 ADR-0010 的地基。

**后果（四条）**：

1. 门禁 `test/style-invariants.test.js` 新增 `§7(a)-7f`：入口必须是 `<button>`、带 `aria-expanded` / `aria-controls`、弹层默认 `hidden`、且 `.theme-pop.hidden { display: none }` 在 CSS 里存在（**本站没有全局 `.hidden`**，少了自己那一条就是常驻）。既有断言一条没减：`§7(a)-6` 里 `.theme-seg .seg-opt` 的 48×44 从「常驻段钮」平移到「弹层里的选项」，`§7(a)-7c` 的「名单只有一份、HTML 里不许出现 `theme-<name>`」原样管着新结构。
2. 变异检查（`.scratch/negcheck/run.mjs`）新增四个变异体，其中三个专打 `7f`：弹层默认展开 / 入口换成 `<div>` / 删掉那条 `.hidden` 规则。**新增一类变异体是现推的**——从当前真文件打补丁生成，不是静态副本：`index.html` 一改，静态副本就会变成"在测一份旧页面"。7 条 → 11 条，各测各的，连带不响。
3. 工单 007 的宽度判据换形：原来量「`.tool-row` 整组不换行」，现在量「入口一颗钮不换行 + 弹层不溢出视口」，且弹层要在**名单最长那一刻**量（四档），不是名单当前长度。007 里故事 16 的读数字段按本表重开。
4. 工单 004（玻璃档材质）多一个合法落点：`.theme-pop .seg`。它同时也是**第一个真弹层**——004 的「材质只进浮层」反向断言从此有了活的观察对象，不再只对着 `.modal` 那类既有对话框。

# 📚 班级作业记录本

教室投影上的一面作业墙：按日期展示当天各科作业，后排学生要能直接读清。
一台触控一体机、一名科代表录入，支持查看、添加、编辑、删除。

## 技术栈

- **后端**: Node.js + Express + SQLite（better-sqlite3）
- **前端**: 纯 HTML + CSS + JavaScript（单页应用，模块化）
- **部署**: 本地/轻量服务器直接运行；生产部署见 [阿里云 FC 方案](DEPLOY_ALIYUN_FC.md)

## 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动服务
npm start

# 3. 打开浏览器访问
# http://localhost:3000
```

使用 SQLite 本地数据库，零配置启动。也可以双击 `start.vbs`（Windows）一键启动并自动打开浏览器。

## 谁在用 · 两个态怎么走

**使用人**：本班科代表一名，在教室那台触控一体机上操作，纯触控（手指点按 + 系统软键盘）。**受众**是同级学生，所以展示态的一切尺寸都按"后排读得到"来定。全站零鉴权（见 [ADR-0001](docs/adr/0001-single-trusted-device-no-auth.md)）：只服务一间教室的一台受信任设备，请只在教室局域网内使用。

页面有两个态，走法是这样：

- **展示态是默认态**（见 [ADR-0003](docs/adr/0003-show-mode-is-the-default-state.md)）。打开 `http://localhost:3000` 就是展示态，刷新、重开机、上课中途 F5 都落回这里。没有编辑按钮、没有勾选框，只有科目网格 + 时钟。
- **编辑态要显式进入**：点右上角"退出展示"胶囊。顶栏随之出现，可以添加/编辑/删除作业、切日期。顶栏第二行是**工具行**——日期导航、字号、暗色、主题四件聚在一处居中（见 [ADR-0010](docs/adr/0010-edit-toolbar-merged-into-topbar.md)）。主题那件是**一颗按钮**，点开才出选项（[ADR-0013](docs/adr/0013-theme-picker-is-a-button-with-a-popover.md)）；按钮上写着当前是哪套，不打开也读得出来。
- **编辑态闲置 5 分钟自动弹回展示态**，最后 1 分钟每 15 秒提示一次；期间摸一下屏幕或开着编辑弹窗就不会走。教室场景下没人会记得手动切回去，所以这一条是设计的一部分，不是提醒。
- 全屏和模式是两件事：展示态会尝试自动进全屏，但浏览器不允许网页取消 Esc 退全屏，所以 Esc 只退全屏、不改模式。

**墙的形状：一科一条、六格常驻、空格标「未布置」。** 这三个词是这面墙的全部结构，也是它最好用的地方——后排可以靠空间记忆读墙。

- **一科一条**（见 [ADR-0005](docs/adr/0005-one-homework-per-subject-per-day.md)）：同一天同一科目在墙上只有一条作业，由数据库唯一索引 `(date, subject_id)` 强制。一门课今天要留两件事，就在**这一条正文里换行**，墙上照原样分行显示——不靠第二条记录。所以没有拖拽排序，也没有"单科多条"的录入入口。
- **六格常驻**（见 [ADR-0006](docs/adr/0006-wall-order-is-a-fixed-subject-table.md)）：语文、数学、英语、物理、化学、生物六个格子**天天都在**，位置固定，左上第一格永远是语文。六个主科每次启动会被补齐回 `subjects` 表（只补不覆盖，表外科目与改过的名字都不动），表外科目排在六个主科**之后**，按建立先后。现在表外科目只能来自历史数据——录入侧已经不再接受新名字（见 [ADR-0011](docs/adr/0011-subjects-are-a-closed-set-of-six.md)）。「删掉一科」因此只对表外科目成立，见下面的「科目列表」。
- **未布置**：某个常驻格子当天没有作业时显示的那两个字。它是陈述不是报错——"这一科今天没留"。整墙一科都没有时是另一句话「今日作业待公布」（明天/昨天分别是「明日作业待公布」「昨天未布置作业」），两层文案各说各的：整墙级说"今天还没有人录"，格子级说"这一科没留"。

编辑态因此有两条改法：点「添加作业」，在**六个科目按钮**里点一个（当天已有作业的科目会**直接回填那一条**让你改，而不是报"已存在"）；或在列表里**点整行**去改那一科——行内只剩一个删除钮，没有编辑钮可对准了。删掉之后该科格子变「未布置」，不是从墙上消失。

`?show=1` 现在只是 `/` 的等价别名，**不再是进展示态的唯一途径**。它（以及展示态本身）的"只读"都只是前端隐藏按钮——`POST` / `PUT` / `DELETE` 接口对任何能访问到服务的人一直开放，不具备任何防护作用。要公网部署必须先自行补鉴权，见 `DEPLOY_ALIYUN_FC.md` 开头的警告。

一体机上想固定字号，用地址参数预设即可：`http://localhost:3000/?scale=1.3`。

## 科目列表

科目就是六个主科：语文、数学、英语、物理、化学、生物（见 [ADR-0011](docs/adr/0011-subjects-are-a-closed-set-of-six.md)，它推翻了 [ADR-0004](docs/adr/0004-subjects-are-open-ended.md) 的开放集合）。录入时点六个按钮之一，没有输入框可打新名字；`POST` / `PUT` 带了表外名字会直接 400，**不写数据库、不动 schema**。

展示网格的行数仍随 `subjects` 表里的科目数自适应（装不下时依次压间距行高 → 缩字号；压到可读下限仍装不下，整面墙才允许上下滚动，见 [ADR-0007](docs/adr/0007-show-mode-falls-back-to-vertical-scroll.md)）——这句话留着是因为**表外科目依然可能被显示**：历史数据或数据修复留下的那一行照旧上墙，排在六个主科之后。

> 「删掉一科」这件事只对**表外科目**成立：六个主科每次启动都会被补齐回来，删掉之后下次启动就又出现了。要真删掉历史数据里残留的「政治」，直接删 `subjects` 表里那一行——它是表外的，不会被补回来。

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/subjects` | 获取科目列表（正常部署下恒为六个主科，外加历史数据里的表外科目） |
| GET | `/api/homeworks?date=2026-09-19` | 获取作业列表（日期可选） |
| POST | `/api/homeworks` | 添加作业（`subject_name` 只认那六个名字，表外名 → 400 且不建科）；**同一天同一科目已有作业 → 409** |
| PUT | `/api/homeworks/:id` | 修改作业（改成"当天已有作业的另一科"同样 409） |
| DELETE | `/api/homeworks/:id` | 删除作业 |

写接口只接受上表这些能力：`completed` 与 `note` 一律返回 400——墙不记录完成状态和备注（见 [ADR-0002](docs/adr/0002-wall-answers-only-todays-homework.md)），数据库里那两列只是留着不再读写。批量导入、批量编辑的端点已删除；`PUT /api/homeworks/reorder`（拖拽排序）也已删除，现在访问它是 404（见 [ADR-0006](docs/adr/0006-wall-order-is-a-fixed-subject-table.md)）。科目必选：`subject_id: null` 且无 `subject_name` 返回 400，「其他（无科目）」这条路径已取消。`subject_name` 与 `subject_id` 走同一道解析：六个名字之内按名找到**已有**那一行，表外名一律 400 且**不往 `subjects` 插行**（见 [ADR-0011](docs/adr/0011-subjects-are-a-closed-set-of-six.md)）；`subject_id` 指向表外科目则仍然放行，那是历史数据改挂的唯一出路。

撞车时返回 **409**（不是覆盖、不是 500）：唯一索引 `(date, subject_id)` 拒掉"同一天同一科目第二条"，错误文案是「`2026-09-19` 的「数学」已经有一条作业了；一科一条，请直接改那一条」。**正常操作撞不到它**——「添加作业」里选一个当天已有作业的科目会直接转成 PUT 回填那一条，409 只在两个标签页同时改同一科时才露面。

### 作业对象字段

```json
{
  "id": 1,
  "subject_id": 2,
  "subject_name": "数学",
  "content": "完成练习册P25-30",
  "date": "2026-09-19",
  "deadline": "2026-09-20 08:00:00",
  "sort_order": 0,
  "created_at": "2026-09-19 21:24:56",
  "updated_at": "2026-09-19 21:24:56"
}
```

`date` 是这条作业**属于哪一天**（挂在哪面墙上），`deadline` 是**什么时候交**，两者独立。录入时死线只给两档粒度：`当天` 或 `次日` + 一个时刻，存成完整的 `YYYY-MM-DD HH:MM:SS`；显示时当天只写时刻，次日写"次日 HH:MM"，超出这两档（历史数据里手动改过的）如实显示成 `MM-DD HH:MM`。改正文不会挪动已存死线的日期。

`sort_order` **字段保留、不再有任何读者**（新写入一律走列默认值 0，只有历史数据里可能还留着当年拖拽留下的非 0 残值）：一科一条之后墙上的顺序由主科优先表决定（见 [ADR-0006](docs/adr/0006-wall-order-is-a-fixed-subject-table.md)），而删字段/删索引是不可逆的 schema 变更，所以留着不动——与 `completed`/`note` 同一套处理方式。

## 功能特点

- ✅ 展示态常驻：整屏科目网格、时钟、5 秒轮询自动刷新，无需人操作
- ✅ 展示态降级阶梯：列数固定 3、行数随科目数走，装不下依次压间距行高 → 二分缩字号，压到可读下限（`FIT_FLOOR = 0.55`）仍装不下才整墙纵向滚动
- ✅ 手动缩放（A− / A+）与自动适配**相乘**叠加，不互相覆盖
- ✅ 编辑态显式进入，闲置 5 分钟自动弹回展示态
- ✅ 按日期查看作业（支持切换日期和"回到今天"）
- ✅ 添加、编辑、删除作业，科目是六个主科的闭集（点按钮选，不打字，表外名后端拒收）
- ✅ 截止时间两档：当天 / 次日
- ✅ 一科一条：正文内换行表达"这科今天有两件事"，墙上照原样分行
- ✅ 暗色模式（手动切换 + 跟随系统）、`prefers-reduced-motion` 适配
- ✅ 主题：**白板风（默认）/ GitHub / Discord / 液态玻璃** 四套在选，每套各有明、暗两档；在编辑态工具行的**主题按钮**里切换，**展示态不可切**（投影时不换脸，见 [ADR-0012](docs/adr/0012-visual-structure-is-per-theme-but-token-only.md) 与 ADR-0010 后果 2）。名单只有一份，写在 CSS 的 `body.theme-*` 块上，`§7(a)-7c` 让按钮与它当场对齐——这句话里的套数随时跟着块走。**Discord 那一套的取值是裁下来的，不是抄来的**：Discord 不发布配色 token 包，它的"官方值"没有可解析出处，所以那两块里一行官方 token 名标注都没有（门禁反过来盯这一格），口径见 [ADR-0015](docs/adr/0015-discord-tier-is-a-ruled-palette-not-a-copied-one.md)。**玻璃折射的是页面自己的内容：换桌面壁纸看不到任何变化**（墙上没有站外背景可透），它改的是浮层的质感，不是墙的背景。
- ✅ 字号调节、响应式触控适配
- ✅ 纯触控可用：全站可点击目标 ≥44×44px（日期导航、字号滑块、行内删除、A−/A+、六个科目按钮、主题弹层里的每一档）。这一条有两半：源码侧由 `test/style-invariants.test.js` 的 `§7(a)-6` 钉住"声明值不低于 44px"，**逐处逐档的实测几何**在展示态与主题弹层上仍待教室真机复测（旧实测读数出自主题化之前，那时弹层还不存在）。
- ✅ 数据持久化存储（SQLite，`journal_mode = DELETE`）

## 数据持久化说明

| 场景 | 数据库 | 持久化方式 |
|----------|--------|-----------|
| **本地开发** | SQLite | 项目根目录 `homework.db` 文件 |
| **阿里云 FC** | SQLite | NAS 文件存储（见 `DEPLOY_ALIYUN_FC.md`） |
| **轻量服务器** | SQLite | 服务器本地硬盘 |

> **注意：** 本项目依赖 better-sqlite3 原生模块，Serverless 平台（如 Vercel）需在目标平台环境重新编译，且文件系统通常只读，不适合直接部署。生产环境推荐阿里云 FC + NAS（有完整方案文档）或自托管轻量服务器。
